# DIE SHRINK — Game Design Document (v0.2)

> 코드네임: `phone-dungeon`
> 제목: **DIE SHRINK** (반도체 공정 용어 "다이 슈링크" ↔ "죽어라, 줄어라"의 이중 의미)
> 장르: 싱글플레이 퍼즐 로그라이트 / 턴제 던전 크롤러
> 플랫폼: **웹** (모바일 세로 우선, 데스크톱 대응) — three.js
> 세션 길이: 1런 10~18분, 1층 1~2분
> 플레이: https://lqez.github.io/phone-dungeon/

### v0.1 → v0.2 변경 요약

| 항목 | v0.1 | v0.2 |
|---|---|---|
| 자원 | HP / MP / Heat / Battery (4개) | **BATTERY / HEAT (2개)** + Health(상한) |
| 마나 | MP (0이 되면 못 씀) | **HEAT 역방향 게이지** — 점진적 페널티 구간 |
| 런 구조 | 소자 던전 4~6개 + 노드맵 분기 | **소자 = 2~3층**, 소자 클리어 후 기판에서 다음 소자 선택 |
| 플랫폼 | 네이티브 (Unity/Godot) | **웹 / three.js** |

> **왜 바꿨나** — v0.1의 Heat는 안개로 식는 자원이라 HP·MP와 회복 채널이 완전히 겹쳤다.
> 세 자원이 전부 "안개를 걷으면 좋아진다"는 같은 방향이라 게이지만 늘고 결정은 늘지 않았다.
> 자원을 늘리는 대신 **이름을 바꿔 겹침을 제거**했다. 자세한 논거는 §5.6.

## 1. 한 줄 요약

**당신의 폰 화면이 투명해지고, 그 아래 기판 위에서 전자 괴물들이 기어다닌다.**
Desktop Dungeons의 "자원 관리 퍼즐" 전투를 계승하되, 무대를 실제 스마트폰 내부 하드웨어로 옮기고, 한 손 엄지 조작과 로그라이트 영구 성장을 얹었다.

## 2. 컨셉

### 2.1 핵심 기둥

| # | 기둥 | 의미 |
|---|------|------|
| P1 | **전투는 퍼즐이다** | 랜덤 회피/명중 없음. 모든 수치가 공개되고, 유한한 자원을 어떤 순서로 태우느냐가 전부. 리셋은 죽음뿐. |
| P2 | **엄지 하나로 끝난다** | 이동·공격·스킬·아이템 전부 한 손으로. 인벤토리 화면 전환 0회. |
| P3 | **무대는 당신의 기기다** | 배경이 판타지가 아니라 지금 손에 쥔 폰. 실제 배터리·발열·시간이 게임에 새어 들어온다. |
| P4 | **죽어도 남는다** | 매 런은 리셋되지만 언락된 클래스·글리프·펌웨어·소자는 영구히 유지된다. |

### 2.2 원작(Desktop Dungeons) 대비 각색

| 항목 | Desktop Dungeons | DIE SHRINK |
|------|------------------|-----------|
| 던전 | 20×20 단일 맵, 1판 = 1런 | 9×13 × 2~3층 = 소자 1개, 소자 3~4개 = 1런 |
| 체력 | HP | **BATTERY** (0 = 방전사) |
| 마나 | MP (0이면 못 씀) | **HEAT** (역방향 — 차오르면 못 씀, 구간별 점진 페널티) |
| 회복 | 안개 걷기 | 동일 (배터리 회복 + 냉각) |
| 아이템 | 인벤토리 소지 후 사용 | **밟는 즉시 발현** (인벤토리 없음) |
| 스킬 | 화면 하단 고정 UI | **캐릭터 탭 → 라디얼 메뉴** |
| 종족 | 인간/엘프/드워프… | **펌웨어** (스톡/루팅/커스텀롬…) |
| 신앙 | 신 숭배, Piety | **데몬 바인딩**, Permission |
| 진행 | 던전·클래스 언락 | 언락 + **PCB 메타 트리** |
| 신규 축 | — | **Battery Health** (층을 내려갈수록 깎이는 체력 상한) |

## 3. 세계관 & 오프닝

### 3.1 설정

당신은 그냥 **사용자(User)** 다. 개발자도 해커도 아니다.
어느 날 폰이 이유 없이 뜨거워지고 배터리가 증발하기 시작한다. 화면을 오래 들여다보다 문득, 화면 너머의 것이 보인다.

기판, 칩, 코일, 셀. 그리고 그 사이를 기어다니는 것들.
버려진 프로세스, 부패한 비트, 회수되지 못한 메모리. 이것들은 **전자 괴물(Electric Vermin)** 이다.

당신의 의식은 터치 입력을 타고 유리 아래로 내려간다. 무기는 손가락이다.

### 3.2 오프닝 연출

```
[0:00]  폰 외관. 유리 위에 홈스크린 아이콘 격자가 켜져 있다.
[0:03]  픽셀들이 하나씩 꺼진다. 알파 페이드가 아니라 서브픽셀이 죽는 디졸브.
[0:07]  유리 = 완전 투명. 그 아래 PCB가 드러난다. 구리 배선, IC 패키지, 배터리 셀.
[0:10]  카메라가 기판으로 하강. 소자들이 하나씩 시안색으로 점등된다.
[0:14]  "기판이 드러났다 — 소자를 탭해 내려가라"
        소자를 고르면 카메라가 그 다이 안으로 파고든다. (Die Shrink)
[0:17]  게이트 격자가 그리드 타일로 정착. 안개가 덮인 첫 층.
```

스킵 가능하되, 스킵 버튼은 `^C` 로 표기.
**구현 상태: ✅ 완료** (`web/game.js`, `bootStep()`)

### 3.3 디에게틱 연동

실제 기기 상태를 게임 규칙으로 끌어온다. **가장 강한 차별화 요소.**

| 실제 기기 상태 | 게임 내 반영 | 상태 |
|---|---|---|
| 배터리 잔량 | 런 시작 시 Battery Health 초기값 ±10% | 🔲 |
| 배터리 20% 이하 | `LOW POWER` 소자 해금 (스탯 반감, 보상 2배) | 🔲 |
| 충전 중 | 열 축적 +15%, 화면 가장자리 붉은 글로우 | 🔲 |
| 심야(00~04시) | `IDLE` 변형 — 몬스터가 잠들어 선공 무료, 깨우면 강화 | 🔲 |
| 다크/라이트 모드 | 기판 솔더마스크 색 전환 | 🔲 |
| 기기 모델명 | 허브 기판 실루엣이 해당 기기 형태로 | 🔲 |

> 웹에서는 Battery Status API가 제한적(Chromium 계열만, 일부는 권한 필요)이다.
> **취득 실패 시 게임 내 시뮬레이션 값으로 폴백**하고, 핵심 재미가 여기 의존하지 않게 설계한다.

## 4. 구조

### 4.1 루프

```
   [부팅: 폰 → 유리 디졸브 → 기판]
                │
                ▼
   ┌──── [기판 허브] ────────────────────────┐
   │   소자(IC) 선택 → 다이 안으로 하강        │
   │        │                                │
   │        ▼                                │
   │   ┌ 소자 던전 (2~3층) ─────────┐          │
   │   │  9×13 그리드                │         │
   │   │  안개 걷기 → 회복 → 전투     │         │
   │   │  → 레벨업 → VIA로 하강      │         │
   │   │  자원·레벨 이월, 회복 없음    │         │
   │   │  VIA 통과마다 HEALTH 감소    │         │
   │   └────────────────────────────┘         │
   │        │ 마지막 층 클리어                  │
   │        └──→ 기판으로 복귀, 소자 장악 표시 ──┘
   │
   └─ 소자 3~4개 장악 → [최종: SECURE ENCLAVE]
                │
          사망 or 클리어 → DATA로 PCB 메타 트리 납땜
```

- **1런 = 소자 3~4개**, 소자당 2~3층 → 총 8~12층.
- 레벨·아이템 효과·자원은 **런 전체에 걸쳐 이월**된다. 층 이동으로 회복되지 않는다.

### 4.2 층 구조가 푸는 문제와, 층 구조가 만드는 문제

**푸는 문제**: 폰 세로 화면에 맞춰 20×20 → 9×13으로 줄이면 유효 안개가 ~300칸에서 ~85칸으로 준다. 결정 횟수가 1/3로 줄어 퍼즐이 얕아진다.
→ 층을 여러 개 쌓아 총량을 복원한다. `85칸 × 3층 ≈ 255칸`.

**만드는 문제**: 층마다 새 안개 85칸이 공짜로 생긴다. 그러면 **"적당히 싸우다 힘들면 내려가서 새 안개로 회복"** 이 최적해가 되어 자원 긴장이 통째로 붕괴한다.

**해법 — Battery Health (배터리 열화)**

| 규칙 | 값 |
|---|---|
| 시작 Health | 100% |
| 최대 배터리 | `10 × 레벨 × Health / 100` |
| VIA 통과 (일반) | Health **−4%p** |
| VIA 통과 (그 층 전멸 후) | Health **−2%p** |
| 회복 | 불가 (희귀 아이템 제외) — **단조 감소** |

리튬 배터리가 충방전 사이클마다 최대 용량을 잃는 실제 현상과 1:1 대응한다.
도망치듯 내려갈수록 체력 상한이 빨리 깎여 후반에 버티지 못한다.
→ **"충분히 털고 갈까, 지금 튈까"** 가 매 층의 저울질이 된다.

HUD의 배터리 바에 표시되는 회색 눈금이 현재 상한선이다.

## 5. 코어 룰

### 5.1 절대 원칙

1. **난수 없음.** 명중률·회피·크리티컬 없음. 데미지는 결정론적 정수. (랜덤은 맵 생성·드랍에만)
2. **모든 정보 공개.** 몬스터 스탯, 교환 결과 예측, 남은 회복량 전부 볼 수 있다.
3. **되돌리기 없음.** Undo 버튼 없음.
4. **몬스터는 움직이지 않는다.** 맵 전체가 처음부터 계산 가능한 퍼즐이다. (일부 `MOBILE` 예외)

### 5.2 탐험과 회복

- 맵은 **안개**로 덮여 있다. 이동하면 인접 8칸의 안개가 걷힌다.
- **새로 걷힌 칸 1개당**: `BATTERY +레벨` / `HEAT −2`
- **안개는 유한하다.** 9×13 = 117칸 중 벽을 뺀 약 85칸이 그 층의 전부.
- 회복량이 레벨에 비례하므로 **안개 1칸의 가치가 매 순간 달라진다.** 이 변동성이 깊이의 정체다.
  (Heat 냉각량은 레벨과 무관한 고정값 — 후반으로 갈수록 냉각이 상대적으로 귀해진다)

### 5.3 전투

- 몬스터를 탭 → **1회 교환**. 내가 때리고 → 살아있으면 반격. 턴 종료.
- 데미지 = `ATK − 상대 DEF` (최소 1)
- `AMBUSH` 몬스터는 첫 교전에서 먼저 때린다.
- **기회공격(attack of opportunity)은 없다.** 몬스터 옆을 지나가거나 인접 상태에서 벗어나는 것은
  완전히 자유롭고, 오직 **플레이어가 명시적으로 공격을 선택했을 때만** 반격이 발생한다.
  > 이것이 "감당 못 할 몬스터는 남겨두고 안개만 걷어 레벨을 올린다"는 전략을 성립시킨다.
  > 지나가기만 해도 맞는다면 맵 이동이 봉쇄되어 퍼즐 자체가 무너지고, 자동 길찾기(§6.3)와도 충돌한다.
- **기본 공격은 열을 올리지 않는다.** 열은 스킬·글리프 전용 자원이다.
  (→ 글리프를 안 쓰는 순수 물리 빌드는 열 관리에서 완전히 자유롭다. §8 `SAFE MODE` 참조)

### 5.4 레벨업 — 게임의 심장

**레벨업 시 배터리 완충 + 열 0.**
"죽기 직전까지 맞으며 레벨업 타이밍을 정확히 맞춘다"는 원작의 핵심 스릴을 그대로 계승한다.

| 몬스터 레벨차 | 획득 XP |
|---|---|
| −2 이하 | 0 |
| −1 | 1 |
| 동급 | 2 |
| +1 | 4 |
| +2 | 7 |
| +3 이상 | 11 |

레벨업 필요 XP: `5, 15, 30, 50, 75, 105, 140, 180, 225, 275, 330, 390` (Lv1→12)

### 5.5 스탯

| 스탯 | Lv1 | 레벨당 |
|---|---|---|
| BATTERY (최대) | 10 | +10 (× Health) |
| ATK | 5 | +5 |
| DEF | 0 | +0 (아이템·클래스로만) |
| HEAT 상한 | 100 | +0 (메타 트리·펌웨어로만) |

몬스터 Lv N: `HP = 11N`, `ATK = 5N`
→ 동레벨끼리는 3~4회 교환에 결판나는 팽팽한 균형.

### 5.6 HEAT — 마나의 역방향 게이지

**MP를 대체한다. 추가 자원이 아니다.**

| Heat | 상태 | 효과 |
|---|---|---|
| 0~69 | `NOMINAL` | — |
| 70~89 | `WARM` | **스킬 비용 ×1.5** |
| 90~99 | `THROTTLED` | **스킬 사용 불가**, ATK −25% |
| 100 | `SHUTDOWN` | **3턴간 공격·스킬 불가** (이동만 가능) |

- 상승: 스킬·글리프 사용. 일부 몬스터(`THERMAL`, `ADWARE`)의 접촉.
- 하강: 안개 1칸당 −2, 대기 1턴당 −1, 레벨업 시 0.

**왜 MP가 아니라 역방향인가**

MP는 이진 상태다 — 있으면 쓰고, 0이면 못 쓴다. Heat는 같은 수학이지만 **점진적 페널티 구간**을 자연스럽게 표현한다.

- `WARM` 구간에서 "지금 쓰면 비싸지지만 쓸 수는 있다"는 저울질이 생긴다. MP로는 만들기 어려운 결정이다.
- 환경이 게이지를 **밀어올릴** 수 있다 — 발열 몬스터, 배터리 셀 스테이지, 실제 기기 충전 상태. "MP를 깎는다"보다 서사적으로 정합적이다.
- 셧다운이 진짜 페널티가 된다: 전투 중 100에 닿으면 도망쳐야 하고, 도망치면 얻어맞는다.

**폐기된 v0.1 설계** — 당시 Heat는 HP·MP와 별개의 세 번째 자원이었고, 안개로 식었다. 세 자원이 전부 같은 채널로 회복되니 경쟁이 아니라 중복이었다. "안개 1칸 = Heat −2 고정"은 레벨·상황과 무관한 선형 값이라 아무 결정도 만들지 않았다. 이름을 바꾸자 문제가 사라졌다.

## 6. 조작 & UI

### 6.1 화면

```
┌────────────────────────────┐
│ DEPTH 03   NAND FLASH 2/3F │ ← 상단 계측 HUD
│ BATT ████████░░░┊  24/30   │   ┊ = Health 상한 눈금
│ HEAT ███░░░░░░░░   34      │
│ LV 3  ATK 15  XP 12/30  WARM│
├────────────────────────────┤
│                            │
│      9 × 13 그리드 (3D)     │ ← 오쏘 카메라, 수직에서 26° 기울임
│      한 화면에 전부         │
│                            │
├────────────────────────────┤
│ › 로그 2줄                  │
└────────────────────────────┘
```

- 던전은 **한 화면에 완전히 들어온다.** 스크롤 없음 — 퍼즐 게임에서 전체 조망은 필수.
- 카메라는 `{tilt, yaw, dist, focus}` 하나로 제어. 런타임에 12°/26°/40° 전환 가능.

### 6.2 시각 언어 — 높이로 구분한다

평면 타일에서는 벽·바닥·몬스터가 전부 비슷한 사각형으로 뭉개진다. 3D의 존재 이유가 여기 있다.

| 요소 | 높이 | 색 | 형태 |
|---|---|---|---|
| 바닥 (걷힌 곳) | 0.14 | 발광하는 청록 | 격자 간격이 보이는 판 |
| 안개 (미탐색) | 0.50 | 무광 슬레이트 | 균일한 덮개 블록 — **아래가 전혀 안 보인다** |
| 구리 벽 | 0.78~0.92 | 구리 주황 | 솟은 블록 (뒤를 가리지 않을 높이) |
| 몬스터 | ~0.5 | 위협도별 (나보다 높으면 적색) | 칩 패키지 + 바닥 링 + 레벨 숫자 + HP바 |
| 플레이어 | 0.55 (부유) | 시안 | 회전하는 발광 큐브 |
| VIA | 0.06 | 구리 | 회전하는 링 + 구멍 |
| 부품 | ~0.3 | 종류별 | 저항 / 커패시터 / 소형 IC |

> **안개 칸은 아무것도 렌더링하지 않는다.** 벽이 안개보다 높으면 실루엣이 비쳐 맵 정보가 누설된다.

### 6.3 입력 — 모든 행동은 2단계 확인

**첫 탭은 계획, 두 번째 탭은 실행.** 예외 없이 이동·공격·스킬 전부 같은 규칙을 따른다.
되돌리기가 없는 게임(P1)에서 오조작으로 턴을 날리는 것이 가장 나쁜 경험이기 때문이다.

| 입력 | 1차 (계획) | 2차 (실행) |
|---|---|---|
| 빈 칸 **탭** | A* 경로를 고스트로 표시, 이동 칸 수 안내 | 경로를 따라 자동 이동 |
| 몬스터 **탭** | 접근 경로 + **붉은 링**, 교환 결과 패널 | 접근 후 교전 |
| **자신 탭** (`Space`) | 라디얼 메뉴 열기 | — |
| 라디얼 슬롯 **탭** | 상세 설명 + 비용 표시 | 발동 (방향 스킬은 조준 단계로) |
| 방향 조준 **탭** | 관통 경로를 앰버로 표시 | 발동 |
| 방향키 · `WASD` | 인접 칸 계획 | 같은 방향 재입력으로 실행 |
| 우상단 `◱` | 카메라 기울기 전환 (12°/26°/40°) | — |

**자동 길찾기 규칙**
- 8방향 A*. 대각 이동 비용 √2, 벽 모서리 사이를 대각으로 빠져나갈 수 없다.
- **밝혀진 칸으로만 경로를 만든다.** 안개 너머는 플레이어가 모르는 정보이므로 경로 계산에서 제외되고,
  안개 칸은 "마지막 한 걸음"으로만 진입할 수 있다.
- **아이템·VIA 칸은 자동으로 우회한다.** 밟는 즉시 발동(§6.5)하므로 경유지로 삼으면 사고가 난다.
  목적지로 직접 지정했을 때만 밟는다.
- 이동 중 **안개가 걷혀 새 몬스터가 드러나면 즉시 멈춘다.**

**터치 판정**: 탭은 화면에 보이는 격자 셀에 정확히 대응한다. 벽·안개 블록은 화면상 반 칸 높이를
차지하므로, 그 측면을 레이캐스팅하면 조준하지 않은 칸이 선택된다. 따라서 피킹은 높이 있는
지오메트리가 아니라 **바닥에 깔린 전용 격자 평면**으로만 판정한다.

### 6.4 라디얼 메뉴

- 플레이어 위치를 화면에 투영해 그 자리에 원형 메뉴를 띄운다. 엄지 스윕 반경(≈120px) 이내, 화면 밖으로 나가지 않게 편심 보정.
- 각 슬롯에 **그 순간의 실제 열 비용**이 찍힌다 — `WARM` 구간이면 숫자가 1.5배로 바뀐 채 표시된다.
- 사용 불가 슬롯은 회색 + 이유 표기(`과열` / `쿨 2` / `셧다운`).
- 슬롯 구성: 클래스 스킬 1~2 + 글리프 최대 4 + 데몬 권능 1.

### 6.5 아이템 — 즉시 발현

인벤토리를 없애 화면 전환을 0으로 만든다.

| 타입 | 표기 | 설명 |
|---|---|---|
| **INSTALL** | 저항 (녹색) | 영구 패시브 — `ATK +2`, `DEF +1` |
| **EXEC** | 커패시터 (앰버) | 즉발 1회 — 배터리 완충, 인접 전체 피해, 열 전량 방출 |
| **PATCH** | 소형 IC (시안) | 조건부 상시 — `WATCHDOG`: 치명 시 1회 자동 복구 |

**전략의 전환**: 아이템은 "언제 쓸까"가 아니라 **"언제 밟을까"** 의 문제가 된다.
전체 회복을 발견해도 지금 만피면 낭비다. 위치를 기억해두고 보스 직전에 되돌아가 밟는다.
→ 맵 전체가 하나의 자원 배치도가 된다.

## 7. 캐릭터 — 사용자에서 시작하는 전직

시작은 **직업 없음 = `USER`**. 판타지 클래스가 아니라 "폰을 쓰는 방식"이 곧 직업이 된다.
1차 전직은 2번째 소자 클리어 시 3개 중 택1. 2차는 `TRANSFORM SCROLL`로 각 1차당 2분기.

```
                       ┌── 멀티터처 Multi-Toucher   (광역·연타)
        탭퍼 Tapper ────┤
       (근접 물리)       └── 포스프레서 Force-Presser (단일·관통)

                       ┌── 컴파일러 Compiler        (글리프 연쇄)
      스크립터 Scripter ┤
        (글리프)         └── 커널해커 Kernel Hacker  (룰 개변·고위험)

                       ┌── 리버서 Reverser          (능력 복제/탈취)
      디버거 Debugger ──┤
       (정보/약점)       └── 익스플로이터 Exploiter   (처형·즉사)
 USER ─┤
                       ┌── 안티바이러스 Antivirus    (정화/멀웨어 특효)
       패쳐 Patcher ────┤
        (회복/보호)       └── 백업데몬 Backup Daemon  (되감기/부활)

                       ┌── 스로틀러 Throttler       (열 순환·지속형)
    오버클러커 Overclocker┤
       (발열/폭주)        └── 번아웃 Burnout         (자폭·올인)

                       ┌── 메시노드 Mesh Node       (다중 소환)
      커넥터 Connector ─┤
        (소환/유틸)       └── 브릿지 Bridge          (공간 조작)
```

### 7.1 `USER` — 사용자

무기는 손가락. 스탯 보너스 없는 완전한 기준점.
- **`TAP`** — 열 +5 / 쿨 3턴. 다음 공격 ×1.5
- **패시브 `학습`**: 처음 보는 몬스터를 처치할 때마다 영구 `DATA` +1 (전직 전 구간이 손해가 아니도록)

### 7.2 1차 전직 (6종)

| 클래스 | 스탯 | 스킬 | 패시브 | 언락 |
|---|---|---|---|---|
| **TAPPER** 탭퍼 | BAT +20%, ATK +10% | `DOUBLE TAP` 열 +12 — 교환 2회 (반격도 2회) | 같은 적 연타 시 ATK +10% 누적(최대 +40%) | 기본 |
| **SCRIPTER** 스크립터 | 열 상한 +15, BAT −10% | `RUN` — 글리프 열 비용 −20% | 글리프 슬롯 4 → **6**, 발견 즉시 해석 | 기본 |
| **DEBUGGER** 디버거 | ATK +5%, DEF +2 | `BREAKPOINT` 열 +15 — 1턴 정지 + 약점 노출(다음 공격 ×2) | 모든 몬스터 스탯 즉시 공개, 아이템·VIA가 안개 너머로 반투명 표시 | 도감 30종 |
| **PATCHER** 패쳐 | BAT +30%, ATK −10% | `HOTFIX` 열 +18 — 최대치 35% 회복 (층당 3회) | 상태이상 지속 −1턴, VIA 하강 시 Health 감소 절반 | 무사망 3연속 클리어 |
| **OVERCLOCKER** 오버클러커 | ATK +25%, BAT −20% | `BOOST` 열 +30 — 이번 턴 ATK ×2 | `WARM` 70→85, `THROTTLED` 90→98. 대신 셧다운 3턴 → **5턴** | 열 90 이상으로 보스 처치 |
| **CONNECTOR** 커넥터 | 열 상한 +10 | `PING` 열 +22 — 데몬 조각 1기 소환 (3턴) | **안개 걷기 반경 1 → 2** (회복 폭증, 대신 안개를 빨리 소진) | 모뎀 소자 클리어 |

### 7.3 2차 전직 (12종)

1차 능력을 **유지한 채** 심화한다.

**탭퍼 계열**
- **`MULTI-TOUCHER`** — `TEN FINGERS` 열 +28: 인접 8칸 전체에 ATK 70%, 반격 없음. 패시브: 인접 적 1기당 ATK +8%
- **`FORCE-PRESSER`** — `3D TOUCH` 열 +25: DEF 완전 무시, ×1.8, 사용 후 1턴 경직. 패시브: 상대 HP가 높을수록 데미지 증가(최대 +50%)

**스크립터 계열**
- **`COMPILER`** — `BUILD` 열 0: 글리프를 버퍼에 최대 3개 적재 후 일괄 실행, 합산 ×1.6 + 부가효과 전부. 패시브: 같은 글리프 연속 사용 시 두 번째부터 비용 절반
- **`KERNEL HACKER`** — `SYSCALL` 열 +45: 이 층의 규칙 하나를 덮어쓴다 (안개 회복 2배 / 전 몬스터 DEF 0 / 레벨업 XP 절반). 패시브: 열이 한계일 때 **배터리를 열 대신 소모** 가능

**디버거 계열**
- **`REVERSER`** — `DISASSEMBLE` 열 +25: 처치한 몬스터의 능력 1개를 이 소자 동안 획득 (최대 2개). 패시브: 이미 처치한 종에게 피해 +20%, 받는 피해 −20%
- **`EXPLOITER`** — `ZERO-DAY` 열 +30: 대상 HP 30% 이하면 **즉사**, 실패 시 열만 소모. 패시브: 약점 노출 대상에게 ×2.5, 처형 성공 시 **열 전량 초기화**

**패쳐 계열**
- **`ANTIVIRUS`** — `QUARANTINE` 열 +20: 2턴 격리(행동·피격 불가), 해제 시 HP 50%로. 패시브: `MALWARE` 계열에 ×2, 상태이상 완전 면역
- **`BACKUP DAEMON`** — `SNAPSHOT` 열 +35: 현재 상태 저장(층당 1회). `RESTORE`: 사망 시 자동 발동. 패시브: 미사용으로 층 클리어 시 다음 층에 2개
  > ⚠️ P1("되돌리기 없음")을 정면으로 위반한다. **층당 1회 + 사전 명시 저장 + 저장 이후 획득물 소실**로 제한해 퍼즐 파괴가 아닌 리스크 감수 도구로 유지할 것. 밸런싱에서 긴장을 붕괴시키면 2차 전직에서 제외한다.

**오버클러커 계열**
- **`THROTTLER`** — `HEAT SINK` 열 −40: 소모한 열 1당 배터리 0.5 회복 (열을 체력으로 환전). 패시브: `THROTTLED`의 ATK −25%가 **+30% 보너스로 반전** → 90~99가 최적 전투 구간이 된다
- **`BURNOUT`** — `THERMAL RUNAWAY` 열 즉시 100: 반경 2에 `현재 열 × 3` 피해, 이후 배터리 1 + 5턴 셧다운. 패시브: 배터리 10% 이하일 때 ATK ×2.5, 열 축적 0

**커넥터 계열**
- **`MESH NODE`** — `BROADCAST` 열 +40: 3기 동시 소환(5턴). 패시브: 소환수 1기당 DEF +2, 소환수 처치분 XP 전액 획득
- **`BRIDGE`** — `TELEPORT` 열 +12: 걷힌 임의의 칸으로 이동. `REROUTE` 열 +25: 벽 1칸을 통로로. 패시브: **아이템을 밟지 않고 통과 가능**, 아이템 위치 상시 표시
  > 즉시 발현 규칙을 유일하게 우회하는 클래스. §6.5의 "언제 밟을까" 퍼즐을 자유롭게 푼다.

## 8. 펌웨어 (종족 대응)

클래스와 직교하는 두 번째 빌드 축.

| 펌웨어 | 효과 | 언락 |
|---|---|---|
| **STOCK** | 페널티 없음. 상태이상 −1턴, BAT +5% | 기본 |
| **ROOTED** | 열 상한 +15, 글리프 비용 −2 / DEF −3, 받는 피해 +10% | 기본 |
| **CUSTOM ROM** | 글리프 슬롯 +2, 시작 글리프 1개 / 층당 1회 랜덤 크래시(1턴 행동불가) | 글리프 15종 수집 |
| **BETA BUILD** | 층 진입마다 랜덤 버프 1 + 랜덤 디버프 1 (사전 확인 불가) | 런 5회 완주 |
| **LEGACY** | 아이템 드랍 +50%, Health 감소 −25% / 전 스탯 −15%, 레벨 상한 8 | 사망 20회 |
| **SAFE MODE** | 상태이상·즉사 면역 / ATK −25%, **글리프 사용 불가** | 글리프 0개로 소자 클리어 |

> `SAFE MODE`는 글리프를 못 쓰고 기본 공격이 열을 올리지 않으므로 **열 게이지가 아예 무의미**해진다.
> 가장 단순한 빌드가 실제로 가장 단순하게 작동한다.

**조합 예시**
- `ROOTED × Kernel Hacker` — 유리대포 극단. 3~4층 내 결판, 그 이상은 못 버팀
- `LEGACY × Reverser` — 저스탯을 능력 복제로 메우는 장기전. 레벨 상한 8이 족쇄
- `SAFE MODE × Force-Presser` — 오직 단일 타격. 가장 정직한 빌드
- `BETA BUILD × Backup Daemon` — 도박 결과가 나쁘면 되감는다

## 10. 데몬 (신앙 대응)

백그라운드 데몬에 권한을 부여한다. 런당 최대 2기. `Permission`을 모아 권능을 사고, 금기를 어기면 회수된다. 음수가 되면 `SIGKILL`.

| 데몬 | Permission 획득 | 금기 | 권능 |
|---|---|---|---|
| `gc` 가비지 컬렉터 | 몬스터 처치 | 아이템을 밟지 않고 남겨둠 | 시체 1구당 배터리 회복 / 층 전체 정화 |
| `sched` 스케줄러 | 최단 경로 이동 | 되돌아가기, 대기 | 추가 턴 / 행동 순서 조작 |
| `cache` 캐시 | 같은 행동 반복 | 새 글리프 습득 | 직전 행동 무료 재실행 |
| `entropy` 엔트로피 | 무작위 선택 | **프리뷰 사용** | 무작위 강력 효과 / 맵 재생성 |
| `cipher` 사이퍼 | 전투 회피, 도주 | 정면 전투 승리 | 완전 은신 / 피해 1회 무효 |
| `boot` 부트로더 | 무손상 층 클리어 | 사망, 스냅샷 사용 | 부활 1회 / Health 10%p 회복 |

> `entropy`의 금기가 "프리뷰 사용"인 것은 P1(결정론)을 자발적으로 포기하는 대가로 힘을 얻는 구조다.
> 게임의 대전제를 플레이어가 스스로 거래하게 만든다.

## 11. 소자 (스테이지)

각 소자는 **한 문장으로 설명되는 기믹** 하나를 가진다. 기판 허브에서 선택해 진입한다.

| 소자 | 층 | 기믹 | 보스 |
|---|---|---|---|
| **TOUCH DIGITIZER** | 2 | 없음 — 격자가 정직하다 | `GHOST TOUCH` |
| **OLED PANEL** | 2 | 밝은 칸 ATK +20%, 어두운 칸 회복 2배 | `BURN-IN` |
| **HAPTIC ENGINE** | 2 | 3턴마다 진동 — 모든 유닛이 1칸 밀린다 | `RESONANCE` |
| **PMIC** | 2 | 5턴마다 전압 변동 — 전 유닛 ATK ×0.5 / ×1.5 토글 | `BROWNOUT` |
| **AUDIO CODEC** | 2 | 전투 소리가 반경 3의 잠든 몬스터를 깨운다 | `FEEDBACK` |
| **NFC COIL** | 2 | 코일 위 칸들이 서로 텔레포트로 연결된다 | `RELAY ATTACK` |
| **CAMERA ISP** | 3 | 렌즈 왜곡 — 중앙은 넓게, 가장자리는 좁게 보인다 | `LENS FLARE` |
| **LPDDR RAM** | 3 | 걷힌 안개가 20턴 후 되돌아온다 (몬스터도 리스폰) | `MEMORY LEAK` |
| **NAND FLASH** | 3 | `BAD SECTOR` — 밟아도 회복되지 않는 칸 | `FRAGMENT` |
| **BASEBAND** | 3 | 3턴마다 가장자리에 침입자가 추가 스폰 | `PACKET STORM` |
| **BATTERY CELL** | 3 | 열 축적 2배. 대신 처치 시 Health 회복 | `THERMAL RUNAWAY` |
| **SoC / AP** | 3 | 맵이 8개 코어 구획으로 나뉘고 구획마다 기믹이 다르다 | `KERNEL PANIC` |
| **SECURE ENCLAVE** | 최종 | 기믹 3개 무작위 중첩, 이전 보스들의 잔해 재등장 | `THE OWNER` |

### 11.1 최종 보스 `THE OWNER`

Secure Enclave 최심부. 지문·홍채·결제 정보가 봉인된 곳.
거기 있는 것은 괴물이 아니라 **기기 소유자의 데이터 인격** — 플레이어 자신의 복제본이다.
이번 런에서 고른 클래스·펌웨어·글리프를 **그대로 미러링**해 싸운다.

> 자기 빌드의 약점을 아는 것이 유일한 공략법이 되는 구조.

## 12. 몬스터

### 12.1 상성

```
   물리(KINETIC) → 논리(LOGIC) → 전기(ELECTRIC) → 열(THERMAL) → 물리
              노이즈(NOISE) : 무상성 (모두에게 ×1)
```

### 12.2 계열

| 계열 | 특징 | 예시 |
|---|---|---|
| `PROCESS` | 정직한 스탯 | 좀비 프로세스, 데드락, 무한루프, 스택 오버플로우 |
| `DATA` | 저HP 고ATK 유리대포 | 비트 로트, 널 포인터, 세그폴트, 배드 섹터 |
| `PHYSICAL` | 고DEF, 단단함 | 정전기(ESD), 부식, 솔더 브리지 |
| `MALWARE` | 상태이상·자원 탈취 | 애드웨어, 랜섬웨어, 루트킷, 웜, 봇넷 |
| `NOISE` | 무작위 행동, **프리뷰 불가** | 화이트노이즈, 지터, 크로스토크 |

### 12.3 태그

`AMBUSH` 첫 교전 선공 / `MOBILE` 이동 / `SPLIT` 처치 시 분열 / `LEECH` 흡혈 /
`THERMAL` 접촉 시 열 +10 / `ENCRYPTED` 스탯 열람 불가 / `SPAWNER` 주기 소환 /
`DRAIN` 열 강제 상승 / `SHIELDED` 첫 피격 무효

## 13. 로그라이트 메타 진행

### 13.1 통화

| 통화 | 획득 | 용도 | 소실 |
|---|---|---|---|
| **GOLD** | 층 내부 | 상점, 즉시 발현 부품 | 런 종료 시 소실 |
| **DATA** | 신규 몬스터 처치, 층 클리어, 도감 갱신 | PCB 메타 트리 납땜 | **영구** |
| **CORE** | 최종 보스, 도전 과제 | 클래스·펌웨어·소자 언락 | **영구** |

> 사망해도 DATA는 전액 보존된다. **실패한 런이 0의 가치를 갖는 순간을 만들지 않는다.**

### 13.2 PCB 메타 트리

허브에서 **실제 회로 트레이스를 납땜해 연결**하는 형태의 영구 성장 트리.
스킬 트리를 판타지 아이콘 격자가 아니라 **PCB 아트 그 자체**로 만드는 것이 비주얼 정체성의 핵심.

| 계열 | 노드 예시 |
|---|---|
| `VRM` 전압 | 시작 배터리 +10 / 레벨당 +2 |
| `CPU` 연산 | 시작 ATK +2 / 레벨업 XP −5% |
| `CACHE` | 글리프 슬롯 +1 / 라디얼 슬롯 +1 / 쿨다운 −1 |
| `COOLING` 방열 | **열 상한 +10** / 냉각 효율 +25% / `WARM` 임계 +5 |
| `BATTERY` 수명 | **VIA 하강 시 Health 감소 −0.5%p** / 시작 Health +5% |
| `NAND` 저장 | 시작 골드 +50 / 드랍률 +10% |
| `RADIO` 통신 | 데몬 소켓 출현 +20% / Permission +15% |

v1 목표 약 40노드.

### 13.3 crash.log — 실패의 유산

사망 시 그 런의 기록이 저장된다.
- 다음 런의 같은 소자에서, 이전에 죽은 위치에 **`CORE DUMP`** 칸이 생성된다.
- 밟으면 당시 골드의 50% 회수 + 사인 표시 — `killed by RANSOMWARE (lv7) — HEAT 100`
- 도감(`dmesg`)에 몬스터별 사망 횟수·평균 생존 턴이 누적된다.

## 14. 아트 & 사운드

### 14.1 비주얼

- **팔레트**: `#07090C` OLED 그라운드(청색 편향) / `#C87137` 구리(주재료) / `#4DE0D0` 시안(플레이어·활성) / `#FFB454` 앰버(경고) / `#FF4D5E` 적(위험) / `#8697A6` 청색 편향 뉴트럴
- 흔한 "검정 + 애시드 그린" 대신 **구리/시안** 축. PCB 트레이스가 실제로 구리색이고, 시안과 보색에 가까워 플레이어가 배경에서 즉시 분리된다.
- **타이포**: 시스템 모노 단일 계열. 대문자 + letter-spacing으로 계측기/터미널 위계. 숫자는 `tabular-nums`.
- **연출 원칙**: 화면 전체 이펙트 금지. 던전이 항상 다 보여야 하므로 이펙트는 타일 경계 안에서.
- **열 표현**: 열이 오르면 플레이어 큐브와 포인트라이트가 시안 → 앰버 → 적으로 변한다.

### 14.2 사운드 (미구현)

- 멜로디 없는 앰비언트 + 하드웨어 노이즈. 코일 훨, 팬 노이즈, 60Hz 전원 험, 버스 지터를 악기로.
- 열이 오르면 코일 훨의 피치가 상승.
- SFX는 전부 실제 전자기기 녹음 기반. 사망 = 전원 차단음.
- 무음 플레이가 완전히 성립해야 한다 (지하철 대응).

## 17. 미결 사항

1. **층당 밀도** — 소자당 2~3층이 맞는가? 1런 8~12층이 10~18분에 들어맞는가?
2. **1차 전직 시점** — 2번째 소자 클리어 후(서사적) vs 런 시작 시 선택(빌드 계획성)?
3. **Health 감소폭** — 일반 −4%p / 전멸 −2%p가 "튀기"를 충분히 억제하는가?
4. **상점** — 즉시 발현 규칙 하에서 상점을 어떻게 설계할 것인가? (사면 그 자리에서 발동)
5. **일일 시드 챌린지** — v1 포함 여부. 원작의 핵심 재방문 동기였음
6. **수익 모델** — 웹 무료 공개 vs 유료. 로그라이트 퍼즐에 광고/에너지는 P1과 정면 충돌
