# DIE SHRINK — Game Design Document (v0.1 초안)

> 코드네임: `phone-dungeon`
> 정식 제목 후보: **DIE SHRINK** (반도체 공정 용어 "다이 슈링크" ↔ "죽어라, 줄어라"의 이중 의미)
> 대안: `SUBSTRATE`, `TEARDOWN`, `BOARD LEVEL`
> 장르: 싱글플레이 퍼즐 로그라이트 / 턴제 던전 크롤러
> 플랫폼: iOS / Android (세로, 한 손 조작)
> 세션 길이: 1런 8~15분, 1스테이지 2~3분

---

## 1. 한 줄 요약

**당신의 폰 화면이 투명해지고, 그 아래 기판 위에서 전자 괴물들이 기어다닌다.**
Desktop Dungeons의 "자원 관리 퍼즐" 전투를 그대로 계승하되, 무대를 실제 스마트폰 내부 하드웨어로 옮기고, 한 손 엄지 조작과 로그라이트 영구 성장을 얹은 모바일 던전 크롤러.

## 2. 컨셉

### 2.1 핵심 기둥 (Design Pillars)

| # | 기둥 | 의미 |
|---|------|------|
| P1 | **전투는 퍼즐이다** | 랜덤 회피/명중 없음. 모든 수치가 공개되고, 유한한 자원을 어떤 순서로 태우느냐가 전부. 리셋은 죽음뿐. |
| P2 | **엄지 하나로 끝난다** | 이동·공격·스킬·아이템 전부 화면 하단부에서 처리. 인벤토리 화면 전환 0회. |
| P3 | **무대는 당신의 기기다** | 배경이 판타지가 아니라 지금 손에 쥔 폰. 실제 배터리·발열·시간이 게임에 새어 들어온다. |
| P4 | **죽어도 남는다** | 매 런은 리셋되지만 언락된 클래스·글리프·펌웨어·던전은 영구히 유지된다. |

### 2.2 원작(Desktop Dungeons) 대비 각색 요약

| 항목 | Desktop Dungeons | DIE SHRINK |
|------|------------------|-----------|
| 던전 | 20×20 단일 맵, 1판 = 1런 | 9×13 소자 맵 × 4~6개 순회 = 1런 |
| 회복 | 안개 걷기 = HP/MP 회복 | 동일 + **방열(Heat 감소)** 추가 |
| 아이템 | 인벤토리 소지 후 사용 | **획득 즉시 발현** (인벤토리 없음) |
| 스킬 | 화면 하단 고정 UI | **캐릭터 탭 → 라디얼 메뉴** |
| 종족 | 인간/엘프/드워프… | **펌웨어** (스톡/루팅/커스텀롬…) |
| 신앙 | 신 숭배, Piety | **데몬 바인딩**, Permission |
| 진행 | 던전·클래스 언락 | 언락 + **PCB 메타 트리** |
| 신규 축 | — | **Heat(발열)**, **Battery(런 자원)** |

## 3. 세계관 & 오프닝

### 3.1 설정

당신은 그냥 **사용자(User)** 다. 개발자도 해커도 아니다.
어느 날 폰이 이유 없이 뜨거워지고 배터리가 증발하기 시작한다. 화면을 오래 들여다보다 문득, 화면 너머의 것이 보인다.

기판, 칩, 코일, 셀. 그리고 그 사이를 기어다니는 것들.
버려진 프로세스, 부패한 비트, 회수되지 못한 메모리. 이것들은 **전자 괴물(Electric Vermin)** 이다.

당신의 의식은 터치 입력을 타고 유리 아래로 내려간다. 무기는 손가락이다.

### 3.2 오프닝 연출 (First 60 seconds)

```
[0:00]  앱 실행. 아무 UI 없이 사용자의 실제 홈 화면을 흉내낸 정적 이미지.
        상단 상태바에 실제 시각·실제 배터리 잔량 표시.
[0:04]  화면이 미세하게 떨린다. 햅틱 1회 (진동 모터 컨셉의 복선).
[0:07]  픽셀들이 하나씩 투명해지기 시작. 유리 아래 회로 실루엣이 배어나온다.
        → 알파 페이드가 아니라 "픽셀 단위 디졸브". LCD 서브픽셀이 꺼지듯.
[0:14]  화면 = 완전 투명. 이제 보이는 건 PCB. 아직 정지된 사진처럼 죽어 있다.
[0:18]  기판 한구석에서 무언가 움직인다. 카메라가 그쪽으로 천천히 줌인.
[0:24]  줌인이 멈추지 않는다. 배율이 계속 올라가며 실크스크린 → 패키지 → 다이 →
        게이트 단위까지 파고든다. (Die Shrink)
[0:32]  게이트 격자가 그리드 타일로 정착. 안개(Fog)가 덮인 첫 던전 맵.
[0:36]  화면 중앙에 커서 같은 점 하나. 그것이 당신이다.
        텍스트: "user@<실제 기기 모델명>:~$ _"
[0:40]  플레이 시작. 튜토리얼 UI는 터미널 프롬프트 형태로만 등장.
```

**중요**: 이 시퀀스는 최초 1회만 풀버전. 이후 실행 시 [0:14]부터 3초로 압축. 스킵 가능하되, 스킵 버튼조차 "`^C`" 로 표기.

### 3.3 디에게틱 연동 (Diegetic Device Integration)

실제 기기 상태를 게임 내 규칙으로 끌어온다. **가장 강한 차별화 요소이므로 MVP에 반드시 포함.**

| 실제 기기 상태 | 게임 내 반영 |
|---|---|
| 기기 모델명 | 허브 기판의 실루엣·칩 배치가 해당 기기 형태로 렌더링 |
| 배터리 잔량 | 런 시작 시 **Battery 자원** 초기값에 ±10% 가감 |
| 배터리 20% 이하 | `LOW POWER` 이벤트 던전 해금 (스탯 반감, 보상 2배) |
| 기기 발열/충전 중 | 던전 내 Heat 축적 속도 +15% (연출: 화면 가장자리 붉은 글로우) |
| 실제 시각 심야(00~04) | `IDLE` 던전 등장 — 몬스터가 잠들어 있어 선공 무료, 대신 깨우면 강화 |
| 저장 공간 부족 | NAND 스테이지에 `BAD SECTOR` 지형 추가 출현 |
| 무음/진동 모드 | 햅틱 던전 `HAPTIC ENGINE` 의 난이도 변형 |

> ⚠️ 권한 최소화: 배터리·다크모드·시각은 무권한 API로 취득 가능. 기기 모델명은 공개 정보.
> 저장공간/발열은 플랫폼별 가용성 확인 필요 (§14 리스크).

## 4. 코어 루프

```
        ┌─────────────────── 메타 루프 (영구) ───────────────────┐
        │                                                        │
   [허브: 메인보드]                                                │
        │  클래스/펌웨어 선택 → 런 시작                              │
        ▼                                                        │
   ┌─ 런 루프 (1회 8~15분) ────────────────────────┐               │
   │                                              │               │
   │   [PCB 노드 맵] ── 다음 소자 선택 (분기)         │               │
   │        │                                     │               │
   │        ▼                                     │               │
   │   [소자 던전 = DD 1판]                         │               │
   │     안개 걷기 → 회복 → 전투 → 레벨업 → 보스       │               │
   │        │                                     │               │
   │        └─ 클리어 시 Battery 소모, 다음 노드로 ──┘               │
   │                                              │               │
   │   4~6개 소자 순회 후 → [최종: Secure Enclave]   │               │
   └────────── 사망 or 클리어 ──────────────────────┘              │
        │                                                        │
        └──→ 획득한 `데이터(Data)` 로 PCB 메타 트리 납땜 ─────────────┘
```

### 4.1 런 구조

- 1런 = **소자 던전 4~6개** + 최종 던전 1개.
- 던전 간 이동은 **PCB 트레이스 노드 맵**(Slay the Spire식 분기)으로 표현. 노드 종류:
  - `◆ 소자` — 일반 던전
  - `▣ 서브루틴` — 소형 던전 (5×7, 2분, 보상 특화)
  - `⬡ 데몬 소켓` — 데몬 바인딩 (신전 대응)
  - `$ 부품상` — 상점
  - `! 예외(Exception)` — 랜덤 이벤트 / 선택지
  - `☠ 엘리트 다이` — 고난도, 2차 전직 스크롤 확정 드랍
- **레벨/스탯은 던전 간 유지**된다 (Slay the Spire식). 단, HP는 던전 클리어 시 **완전 회복되지 않는다** — 클리어 보너스로 최대 HP의 30%만 회복. 이것이 런 전체를 관통하는 긴장의 주축.

### 4.2 Battery — 런 자원

- 런 시작 시 `Battery = 100%` (실제 기기 잔량에 따라 90~110%).
- 소비: 소자 던전 진입 −15%, 서브루틴 −8%, 상점 사용 −5%, 부활 −40%.
- 0%가 되면 즉시 런 종료(= 방전사). **시간 제한이 아니라 "몇 개의 방을 감당할 수 있는가"의 예산.**
- 충전 아이템은 희귀하고, 대개 "지금 HP를 팔아 Battery를 산다" 형태의 트레이드오프.

## 5. 코어 룰 (전투 & 탐험)

### 5.1 절대 원칙

1. **난수 없음.** 명중률·회피·크리티컬 확률 전부 없음. 데미지는 결정론적 정수.
   (랜덤은 맵 생성·드랍 테이블에만 존재)
2. **모든 정보 공개.** 몬스터 스탯, 예상 교환 결과, 남은 회복량 전부 볼 수 있다.
3. **되돌리기 없음.** Undo 버튼 없음. 단, 이동만 한 턴은 예외 (§6.4).

### 5.2 탐험과 회복

- 맵은 **안개(Fog)** 로 덮여 있다. 이동 시 인접 8타일의 안개가 걷힌다.
- **새로 걷힌 타일 1개당**:
  - `HP +⌈Lv × 1.5⌉`
  - `MP +1` (10타일당 1이 아니라 던전 축소를 반영해 상향)
  - `Heat −2`
- **안개는 유한 자원이다.** 9×13 = 117타일 중 벽·구조물을 뺀 약 85타일이 전부. 다 걷으면 회복 수단이 사라진다.
  → "지금 이 몬스터를 잡기 위해 안개를 얼마나 태울 것인가"가 게임의 전부.
- 예외: **RAM 스테이지**는 걷힌 안개가 20턴 후 재생성된다(휘발성 메모리). 대신 몬스터도 리스폰.

### 5.3 전투

- 몬스터를 탭 → **1회 공격 교환**. 내가 때리고 → 살아있으면 반격. 그것으로 턴 종료.
- 데미지 = `ATK − 상대 DEF` (최소 1). 속성 상성은 ±50%.
- **선공(First Strike)**: 내 레벨 ≥ 몬스터 레벨 이거나 특정 스킬 보유 시. 반대로 `AMBUSH` 속성 몬스터는 항상 선공.
- **도주**: 인접 상태에서 다른 타일로 이동하면 도망 가능하나, 몬스터가 무료로 1대 때린다.
- 몬스터는 **움직이지 않는다** (일부 `MOBILE` 속성 예외). 이것이 퍼즐 성립의 전제.

### 5.4 레벨업 — 게임의 심장

- **레벨업 시 HP/MP 완전 회복.**
  → "죽기 직전까지 맞으며 레벨업 타이밍을 정확히 맞춘다"는 원작의 핵심 스릴을 그대로 계승.
- XP: 처치한 몬스터의 상대 레벨 기준.

| 몬스터 레벨차 | 획득 XP |
|---|---|
| −2 이하 | 0 |
| −1 | 1 |
| 동급 | 2 |
| +1 | 4 |
| +2 | 7 |
| +3 이상 | 11 |

- 레벨업 필요 XP: `5, 15, 30, 50, 75, 105, 140, 180, 225, 275` (Lv1→10)

### 5.5 기본 스탯 (Lv1 사용자 기준)

| 스탯 | 초기값 | 레벨당 |
|---|---|---|
| HP | 10 | +10 |
| ATK | 5 | +5 |
| DEF | 0 | +0 (장비·클래스로만) |
| MP (RAM) | 10 | +0 (펌웨어·글리프로만) |
| Heat 상한 | 100 | +0 |

몬스터 Lv N 기준값: `HP = 11 × N`, `ATK = 5 × N`. (레벨이 같으면 서로 3~4대 교환에 죽는 팽팽한 균형)

### 5.6 Heat — 신규 자원 축

폰 컨셉에 맞춰 추가하는, 원작에 없는 세 번째 축.

- 스킬·글리프 사용 시 `Heat` 축적. 전투 교환마다 +3.
- 탐험(안개 1타일)당 −2, 대기(Wait)당 −1.
- **임계치 도달 시 THROTTLE 상태**:

| Heat | 상태 | 효과 |
|---|---|---|
| 0~59 | `NOMINAL` | — |
| 60~79 | `WARM` | MP 회복 −50% |
| 80~99 | `THROTTLED` | ATK −30%, MP 회복 정지 |
| 100 | `THERMAL SHUTDOWN` | 3턴 행동 불가 (사실상 사형선고) |

- **설계 의도**: MP만으로는 "스킬 난사 후 안개로 리필"이 최적해가 되어 지루해진다. Heat는 *같은 안개 자원을 두고 MP와 경쟁*시켜 선택을 만든다.
- 오버클러커 계열은 Heat를 **자원으로 전환**해 이 룰을 뒤집는다.

## 6. 조작 & UI

### 6.1 화면 레이아웃 (세로, 한 손 엄지)

```
┌────────────────────────────┐
│ ▓ HP ████████░░  80/100    │ ← 상단: 스탯 바 (얇게, 정보만)
│ ▓ MP ██████░░░░  6/10      │
│ ▓ HEAT ███░░░░░  34  BAT82%│
├────────────────────────────┤
│                            │
│                            │
│      9 × 13 그리드          │ ← 중앙: 던전. 한 화면에 전부.
│      (스크롤 없음)           │    타일 ≈ 44dp (터치 최소 규격 충족)
│                            │
│                            │
│                            │
├────────────────────────────┤
│  [소자맵]  [로그]   [일시정지] │ ← 하단: 엄지 도달 영역
└────────────────────────────┘
```

- 던전은 **한 화면에 완전히 들어온다.** 스크롤/팬 없음 — 퍼즐 게임에서 전체 조망은 필수.
- 대형 던전(엘리트/보스, 9×20)만 세로 스크롤 허용하되, 핀치로 전체 보기 가능.

### 6.2 입력 규칙

| 입력 | 동작 |
|---|---|
| 빈 타일 **탭** | 인접이면 1스텝, 멀면 최단 경로 자동 이동 (안개 걷힌 구역 한정) |
| 몬스터 **탭** | 1회 공격 교환 |
| 몬스터 **롱프레스** | **전투 프리뷰 팝업** — 교환 후 내 HP / 적 HP / Heat 예측치 |
| **내 캐릭터 탭** | **라디얼 메뉴 전개** (§6.3) |
| 두 손가락 **핀치** | 맵 전체 조망 / 미니맵 |
| 화면 좌→우 **스와이프** | 로그 패널 (이번 런에서 벌어진 일) |
| 빈 타일 **더블탭** | 대기(Wait) 1턴 — Heat −1 |

### 6.3 라디얼 메뉴 (스킬·행동)

**사용자 요청 사양의 핵심 구현부.**

```
        캐릭터 탭 (누른 채 유지)
                ↓
         ╭───────────────╮
        ╱   ⚡ SURGE      ╲          · 슬롯 최대 8개 (기본 6개 노출)
       │  🛡 SHIELD   🔍   │         · 손가락을 떼지 않고 원하는 방향으로
       │      [ME]   SCAN  │           드래그 → 놓으면 발동
       │  ♻ PURGE    ⏱     │         · 중앙(원점)에서 떼면 취소
        ╲   💾 SAVE   HALT ╱          · 각 슬롯에 MP/Heat 비용 각인
         ╰───────────────╯            · 사용 불가 슬롯은 회색 + 이유 툴팁
                ↓
         타겟 필요 스킬이면 → 사거리 하이라이트 → 대상 탭
```

- **한 손 원칙**: 라디얼 반경은 엄지 스윕 반경(≈120dp) 이내. 캐릭터가 화면 상단에 있으면 메뉴가 아래쪽으로 편심 배치되어 항상 엄지가 닿는다.
- **드래그 중 실시간 프리뷰**: 슬롯 위에 손가락이 머무는 동안, 맵 위에 해당 스킬의 영향 범위와 예상 수치가 오버레이된다. 떼기 전까지 아무것도 확정되지 않음.
- **햅틱**: 슬롯 진입 시 소프트 틱, 사용 불가 슬롯은 더블 틱(거부감).
- 슬롯 구성: `클래스 스킬 1~2` + `글리프 최대 4` + `데몬 권능 1`.

### 6.4 아이템 — 즉시 발현

**사용자 요청 사양.** 인벤토리를 없애서 모바일에서의 화면 전환을 0으로 만든다.

- 필드의 아이템 타일을 **밟는 순간 즉시 발동**. 소지·관리 개념 없음.
- 따라서 아이템은 세 종류로 재편된다:

| 타입 | 표기 | 설명 | 예 |
|---|---|---|---|
| **INSTALL** | 🔧 초록 | 영구 패시브. 이번 런 내내 유지 | `+5 ATK`, `안개 회복 +25%` |
| **EXEC** | ⚡ 노랑 | 즉발 1회성 | HP 전량 회복, 인접 전체 20딜 |
| **PATCH** | ♻ 파랑 | 조건부 상시 트리거 | "HP 20% 이하 시 1회 40 회복" |

- **핵심 전략 전환**: 아이템은 "언제 쓸까"가 아니라 **"언제 밟을까"** 의 문제가 된다.
  - 필드 아이템은 그 자리에 계속 남아있고, 안개를 걷어 발견해도 밟지 않으면 발동하지 않는다.
  - 예: 전체 회복 `EXEC`를 발견했지만 지금 HP가 만땅이면 낭비다. 보스전 직전까지 아껴두고, 그 위치를 기억해 두었다가 정확한 순간에 되돌아가 밟는다.
  - 이 "아이템 위치 = 세이브 포인트" 감각이 맵 전체를 하나의 자원 배치도로 만든다.
- 상점 구매도 동일: 사면 그 자리에서 즉시 발현. 따라서 **상점 방문 타이밍 자체가 전략**이다.
- 밟기 방지: 아이템 타일 위를 지나가야 할 때는 자동 경로가 우회한다. 강제 통과 시 확인 다이얼로그 1회.

## 7. 캐릭터 — 사용자에서 시작하는 전직 트리

### 7.1 설계 원칙

- 시작은 **직업 없음 = `USER`**. 판타지 클래스가 아니라 "폰을 쓰는 방식"이 곧 직업이 된다.
- **1차 전직**: 런 중 2번째 던전 클리어 시, 3개 후보 중 택1 (Slay the Spire식 카드 선택 UI).
- **2차 전직**: 5번째 던전 이후 또는 엘리트 처치 시 획득하는 `TRANSFORM SCROLL`로. 각 1차당 2개 분기.
- 1차 6종 × 2차 2분기 = **총 12개 2차 클래스**.
- 2차 전직은 1차 능력을 **유지한 채 심화**한다 (덮어쓰기 아님).

### 7.2 전직 트리 전체도

### 7.3 기본 클래스

#### `USER` — 사용자
- **컨셉**: 아무것도 모르는 채 유리 아래로 떨어진 평범한 사람. 무기는 손가락.
- 스탯: 전부 기본값. 보너스 없음.
- 고유 스킬 **`TAP`** — MP 0 / Heat +2 / 쿨 3턴. 다음 공격 데미지 +50%.
- **패시브 `학습(Learning)`**: 이번 런에서 처음 보는 몬스터를 처치할 때마다 영구 `데이터` +1. (메타 통화 수급 = 전직 전 구간이 손해가 아니도록)
- 설계 의도: 강하지 않지만 약하지도 않은 완전한 기준점. 튜토리얼 구간(1~2던전)을 담당.

### 7.4 1차 전직 (Tier 1) — 6종

#### ① `TAPPER` 탭퍼 — 근접 물리
- **컨셉**: 터치를 무기화. 탭, 더블탭, 롱프레스가 곧 검술이다.
- 스탯: HP +20%, ATK +10%
- **`DOUBLE TAP`** — MP 2 / Heat +5. 한 턴에 공격 교환 2회. 단, 반격도 2번 받는다.
- **패시브 `연타 감지`**: 같은 적을 연속으로 때릴수록 ATK +10% 누적(최대 +40%). 다른 적을 때리거나 이동하면 초기화.
- 언락 조건: 기본 개방.

#### ② `SCRIPTER` 스크립터 — 마법 / 글리프
- **컨셉**: 주운 코드 조각을 이해하지 못한 채 실행한다. 글리프 = 명령어.
- 스탯: MP +10, HP −10%
- **`RUN`** — 장착한 글리프의 MP 비용 −1 (최소 1).
- **패시브 `인터프리터`**: 글리프 슬롯 4 → **6**. 던전 내 발견 글리프 자동 해석(비용 미리보기).
- 언락 조건: 기본 개방.

#### ③ `DEBUGGER` 디버거 — 정보 / 약점
- **컨셉**: 모든 존재는 버그다. 재현 조건만 찾으면 된다.
- 스탯: ATK +5%, DEF +2
- **`BREAKPOINT`** — MP 3 / Heat +4. 대상을 1턴 정지시키고 **약점(Weak Point)** 노출. 노출된 적에게 다음 공격 데미지 ×2.
- **패시브 `스택 트레이스`**: 처음 보는 몬스터도 전체 스탯·속성·특수능력 즉시 공개. 맵 내 아이템/함정 위치가 안개 너머로 반투명 표시.
- 언락 조건: 몬스터 도감 30종 채우기.

#### ④ `PATCHER` 패쳐 — 회복 / 보호
- **컨셉**: 부서진 것을 임시로 때운다. 근본 해결은 아니지만, 지금은 버틴다.
- 스탯: HP +30%, ATK −10%
- **`HOTFIX`** — MP 4 / Heat +3. 최대 HP의 35% 회복. 던전당 3회 제한.
- **패시브 `무결성 검사`**: 던전 클리어 보너스 회복 30% → **60%**. 상태이상 지속시간 −1턴.
- 언락 조건: 사망 없이 던전 3연속 클리어.

#### ⑤ `OVERCLOCKER` 오버클러커 — 발열 / 폭주
- **컨셉**: 정격을 넘긴다. 더 빠르게, 더 뜨겁게, 더 짧게.
- 스탯: ATK +25%, HP −20%
- **`BOOST`** — MP 0 / **Heat +25**. 이번 턴 ATK ×2.
- **패시브 `열 내성`**: `THROTTLED` 진입 임계치가 80 → **95**. 즉, Heat 94까지는 페널티 없이 달릴 수 있다. 대신 100 도달 시 셧다운 지속 3턴 → **5턴**.
- 언락 조건: Heat 90 이상 상태로 보스 처치.

#### ⑥ `CONNECTOR` 커넥터 — 소환 / 유틸
- **컨셉**: 혼자 싸우지 않는다. 무선으로 다른 소자의 것들을 불러온다.
- 스탯: 전부 기본, MP +5
- **`PING`** — MP 5 / Heat +2. `데몬 조각` 1기 소환. HP 5×Lv, ATK 3×Lv, 3턴 후 소멸. 소환수는 자동으로 인접 적을 공격.
- **패시브 `안테나`**: 안개 걷기 반경이 인접 8타일 → **반경 2 (24타일)**. 회복 효율이 실질적으로 폭증하지만, 던전의 유한 안개를 그만큼 빨리 소진한다.
- 언락 조건: 모뎀(Baseband) 스테이지 클리어.

### 7.5 2차 전직 (Tier 2) — 12종

#### 탭퍼 계열

**`MULTI-TOUCHER` 멀티터처** — 광역·연타
- `TEN FINGERS` — MP 6 / Heat +12. 인접 8타일 전체에 ATK 70% 데미지. 반격 없음.
- 패시브 `제스처`: 인접한 적 수 1기당 ATK +8%.
- 컨셉: 열 손가락이 동시에 화면을 두드린다.

**`FORCE-PRESSER` 포스프레서** — 단일·관통
- `3D TOUCH` — MP 5 / Heat +10. 상대 DEF **완전 무시**, 데미지 ×1.8. 사용 후 1턴 경직.
- 패시브 `압력 감지`: 상대 HP가 나보다 높을수록 데미지 증가 (최대 +50%).
- 컨셉: 한 점을 끝까지 누른다. 유리가 깨질 때까지.

#### 스크립터 계열

**`COMPILER` 컴파일러** — 글리프 연쇄
- `BUILD` — MP 0. 이번 턴 사용한 글리프를 **버퍼에 적재**. 최대 3개까지 쌓은 뒤 한 번에 실행하면 합산 데미지 ×1.6 + 부가효과 전부 발동.
- 패시브 `최적화`: 같은 글리프를 연속 사용하면 두 번째부터 MP 비용 절반.
- 컨셉: 즉흥 실행이 아니라, 빌드하고 배포한다.

**`KERNEL HACKER` 커널해커** — 룰 개변
- `SYSCALL` — MP 8 / Heat +20. 던전 규칙 하나를 이번 던전 동안 덮어쓴다. (3개 후보 중 택1: "안개 회복 2배" / "모든 몬스터 DEF 0" / "레벨업 XP 요구량 절반")
- 패시브 `권한 상승`: MP가 0일 때 **HP를 MP 대신 소모** 가능 (1 MP = 5 HP).
- 컨셉: 게임을 이기는 게 아니라, 게임의 규칙에 접근한다. 가장 강력하고 가장 자멸적이다.

#### 디버거 계열

**`REVERSER` 리버서** — 복제·탈취
- `DISASSEMBLE` — MP 6 / Heat +8. 처치한 몬스터의 특수능력 1개를 **이번 던전 동안 자기 것으로** 획득 (최대 2개 동시 보유).
- 패시브 `심볼 테이블`: 이미 한 번 처치한 종의 몬스터에게 데미지 +20%, 받는 데미지 −20%.
- 컨셉: 뜯어보면 결국 다 같은 코드다.

**`EXPLOITER` 익스플로이터** — 처형
- `ZERO-DAY` — MP 7 / Heat +15. 대상 HP가 **30% 이하면 즉사**. 실패 시(30% 초과) MP만 소모되고 아무 일도 일어나지 않는다.
- 패시브 `취약점 스캐너`: 노출된 약점(Weak Point) 상태 적에게 데미지 ×2 → **×2.5**. 처형 성공 시 Heat 전량 초기화.
- 컨셉: 정면 대결은 하지 않는다. 이미 열려 있는 문으로 들어간다.

#### 패쳐 계열

**`ANTIVIRUS` 안티바이러스** — 정화
- `QUARANTINE` — MP 5 / Heat +6. 대상을 2턴간 격리(행동·반격 불가, 데미지도 못 받음). 격리 해제 시 대상 HP 50%로 감소.
- 패시브 `시그니처 DB`: `MALWARE` 계열 몬스터(랜섬웨어·루트킷·웜·봇넷)에게 데미지 ×2, 이들의 상태이상 완전 면역.
- 컨셉: 죽이는 게 아니라 격리하고 삭제한다.

**`BACKUP DAEMON` 백업데몬** — 되감기
- `SNAPSHOT` — MP 6 / Heat +10. 현재 상태(HP/MP/위치/맵)를 저장. 던전당 1회.
- `RESTORE` — MP 0. 저장 지점으로 즉시 복귀. **사망 시 자동 발동** (스냅샷 보유 시).
- 패시브 `증분 백업`: 던전 클리어 시 스냅샷 미사용이면 다음 던전에 스냅샷 2개.
- 컨셉: 이 게임의 유일한 되돌리기. 그래서 가장 비싸다.
- ⚠️ **밸런스 주의**: "리셋은 죽음뿐"(P1)을 정면으로 위반하는 클래스. 던전당 1회 + 명시적 사전 저장 + 저장 이후 얻은 아이템 소실로 제한하여 *퍼즐 파괴가 아닌 리스크 감수 도구*로 유지할 것.

#### 오버클러커 계열

**`THROTTLER` 스로틀러** — 열 순환
- `HEAT SINK` — MP 0 / Heat −40. 소모한 Heat 1당 HP 0.5 회복. (Heat를 HP로 환전)
- 패시브 `써멀 스로틀링`: `THROTTLED` 상태의 ATK −30% 페널티가 **ATK +30% 보너스로 반전**. Heat 80~99 구간이 최적 전투 구간이 된다.
- 컨셉: 뜨거움을 견디는 게 아니라, 뜨거움 위에서 산다.

**`BURNOUT` 번아웃** — 올인
- `THERMAL RUNAWAY` — MP 0 / Heat 즉시 100. 인접 반경 2 전체에 `현재 Heat × 3` 데미지. 사용 후 자신은 HP 1이 되고 5턴 셧다운.
- 패시브 `최후의 클럭`: HP가 최대치의 10% 이하일 때 ATK ×2.5, Heat 축적 0.
- 컨셉: 한 번만 쓸 수 있는 클래스. 그 한 번을 어디에 쓸 것인가.

#### 커넥터 계열

**`MESH NODE` 메시노드** — 다중 소환
- `BROADCAST` — MP 9 / Heat +8. `데몬 조각` 3기 동시 소환, 지속 5턴.
- 패시브 `노드 링크`: 소환수 1기당 자신의 DEF +2, 소환수가 처치한 몬스터의 XP는 전액 자신에게.
- 컨셉: 혼자서는 약한 신호도, 여럿이면 망이 된다.

**`BRIDGE` 브릿지** — 공간 조작
- `TELEPORT` — MP 4 / Heat +5. 안개가 걷힌 임의의 타일로 즉시 이동. 이동 거리만큼 Heat 추가.
- `REROUTE` — MP 7. 벽 1칸을 통로로 바꾼다 (배선 재연결).
- 패시브 `트레이스`: 아이템 타일 위를 **밟지 않고 통과** 가능. 아이템 위치를 항상 미니맵에 표시.
- 컨셉: 즉시 발현 아이템 규칙을 유일하게 우회하는 클래스. §6.4의 "언제 밟을까" 퍼즐을 자유롭게 푼다.

## 10. 데몬 (신앙 대응)

원작의 신 숭배 시스템을 **백그라운드 데몬에 권한을 부여**하는 것으로 치환.

- 던전 노드 `⬡ 데몬 소켓`에서 **바인딩**. 런당 최대 2기.
- **Permission** 포인트를 모아 권능을 산다. 데몬이 싫어하는 행동을 하면 Permission이 회수되고, 음수가 되면 **`SIGKILL`** — 강력한 저주.

| 데몬 | Permission 획득 | 금기 | 권능 |
|---|---|---|---|
| `gc` 가비지 컬렉터 | 몬스터 처치 시 시체 정리 | 아이템을 밟지 않고 남겨둠 | 시체 1구당 HP 회복 / 맵 전체 정화 |
| `sched` 스케줄러 | 최단 경로로만 이동 | 되돌아가기, 대기 | 추가 턴 획득 / 몬스터 행동 순서 조작 |
| `cache` 캐시 | 같은 행동 반복 | 새 글리프 습득 | 직전 행동 무료 재실행 / 상태 저장 |
| `entropy` 엔트로피 | 무작위 선택지 고르기 | 프리뷰(롱프레스) 사용 | 무작위 강력 효과 / 맵 재생성 |
| `cipher` 사이퍼 | 전투 회피, 도주 | 정면 전투 승리 | 완전 은신 / 데미지 전액 무효 1회 |
| `boot` 부트로더 | 던전 무손상 클리어 | 사망, 스냅샷 사용 | 부활 1회 / 레벨 1 리셋 후 전 스탯 유지 |

- **디자인 노트**: `entropy`의 금기가 "프리뷰 사용"인 것은 P1(결정론)을 자발적으로 포기하는 대가로 힘을 얻는 구조. 게임의 대전제를 플레이어가 스스로 거래하게 만든다.

Secure Enclave 최심부. 지문·홍채·결제 정보가 봉인된 곳.

### 13.2 PCB 메타 트리

허브(메인보드) 화면에서 **실제 회로 기판의 트레이스를 납땜해 연결**하는 형태의 영구 성장 트리.
스킬 트리 UI를 판타지 아이콘 격자가 아니라 **PCB 아트 그 자체**로 만드는 것이 비주얼 정체성의 핵심.

```
   ┌──[VRM]────[CPU]────[GPU]──┐        · 노드 = 실제 부품 실크스크린
   │    │        │        │    │        · 연결선 = 구리 트레이스 (해금 시 빛이 흐름)
   │  [PMIC]  [CACHE]  [ISP]   │        · 납땜 = DATA 소모
   │    │        │        │    │        · 미해금 구간은 회로가 끊겨 있고 어둡다
   └──[BAT]────[RAM]────[NAND]─┘
```

**주요 노드 (v1 기준 약 40개)**

| 계열 | 노드 예시 |
|---|---|
| `VRM` 전압 | 시작 HP +10 / 레벨당 HP +2 / 던전 클리어 회복 +10% |
| `CPU` 연산 | 시작 ATK +2 / 레벨업 필요 XP −5% / 선공 조건 완화 |
| `CACHE` 캐시 | 글리프 슬롯 +1 / 라디얼 메뉴 슬롯 +1 / 스킬 쿨다운 −1 |
| `PMIC` 전력 | Battery 초기값 +10% / 던전 진입 소모 −2% |
| `THERMAL` 방열 | Heat 상한 +10 / 방열 효율 +25% / THROTTLE 임계치 +5 |
| `NAND` 저장 | 시작 골드 +50 / 아이템 드랍률 +10% / 상점 노드 출현율 +15% |
| `RADIO` 통신 | 데몬 소켓 출현율 +20% / Permission 획득 +15% |

### 13.3 언락 체계

| 대상 | 개수 | 언락 방식 |
|---|---|---|
| 1차 클래스 | 6 | 2개 기본 개방, 4개는 조건부 (§7.4) |
| 2차 클래스 | 12 | 해당 1차 클래스로 런 3회 완주 + `TRANSFORM SCROLL` 최초 획득 |

### 13.4 로그 시스템 — 실패의 유산

사망 시 그 런의 전체 기록이 **`crash.log`** 로 저장된다.

- 다음 런의 같은 소자 던전에 진입하면, 이전 런에서 죽었던 위치에 **`CORE DUMP`** 타일이 생성된다.
- 밟으면: 그때 소지했던 골드의 50% 회수 + 당시 사망 원인 표시 ("`killed by RANSOMWARE (lv7) — HEAT 100`").
- 이는 서사적 장치이자, 학습 피드백이자, 반복 플레이의 동기다.
- 도감(`dmesg`)에는 몬스터별 사망 횟수·평균 생존 턴이 누적 기록된다.

## 14. 아트 & 사운드 디렉션

### 14.1 비주얼

- **베이스**: 순흑 배경(OLED 진짜 검정 — 배터리 절약이자 컨셉). 그 위에 **PCB 실크스크린 화이트**와 **네온 시안/앰버**.
- **팔레트**: `#000000` / `#0A0E12` (기판 다크그린 대신 근미래 흑) / `#00E5C7` (시안·플레이어) / `#FF9E1B` (앰버·경고) / `#FF3355` (레드·Heat) / `#E8EDF0` (실크스크린 화이트)
- **타일**: 픽셀아트가 아닌 **벡터 + 미세 그레인**. 고DPI 폰에서 픽셀아트는 흐려지거나 과대해진다.
- **몬스터**: 유기체가 아니라 **글리치·회로 형상**. 다리 대신 배선, 눈 대신 LED, 몸통은 패키지 실루엣.
- **연출 원칙**: 화면 전체 이펙트는 금지. 던전 전체가 항상 보여야 하므로 이펙트는 타일 경계 안에서만.
- **Heat 표현**: Heat가 오르면 UI 프레임과 화면 가장자리에 붉은 글로우가 번지고, 그리드 선이 미세하게 흔들린다(열 아지랑이 셰이더).

### 14.2 사운드

- **음악**: 멜로디 없는 앰비언트 + 하드웨어 노이즈. 코일 훨(coil whine), 팬 노이즈, 전원 험(60Hz), 데이터 버스 지터를 악기로 사용.
- 던전 진행도에 따라 노이즈 레이어가 쌓인다. Heat가 오르면 코일 훨의 피치가 상승.
- **SFX**: 전부 실제 전자기기 녹음 기반. 탭 = 정전식 터치 클릭, 공격 = 릴레이 스위칭, 사망 = 전원 차단음(pop + 잔향 소멸).
- **햅틱**: 사운드와 1:1 매칭. 무음 플레이가 완전히 성립해야 한다 (지하철 플레이 대응).

## 16. 개발 로드맵

### Phase 0 — 코어 검증 프로토타입 (4주)
> **검증 질문: 9×13 그리드에서 안개 자원 퍼즐이 여전히 재미있는가?**
- 단일 던전 1개(터치 디지타이저), `USER` 클래스만, 몬스터 3종
- 탐험·회복·전투·레벨업 룰만. 아트 없음(도형)
- **여기서 재미가 없으면 이후 전부 무의미하다. 다른 것을 만들지 말 것.**

### Phase 1 — 조작 검증 (3주)
- 라디얼 메뉴, 롱프레스 프리뷰, 즉시 발현 아이템
- 검증: 한 손으로 5분 플레이가 편안한가, 오조작률은 얼마인가

### Phase 2 — 런 구조 (5주)
- PCB 노드 맵, Battery, 던전 4개, 1차 클래스 6종
- 검증: 8~15분 런의 페이싱이 맞는가

### Phase 3 — 메타 & 깊이 (6주)
- PCB 메타 트리, 2차 전직 12종, 펌웨어 6종, 데몬, crash.log
- 검증: 3회차, 10회차, 30회차 플레이에 각각 새로운 동기가 있는가

### Phase 4 — 폴리시 (6주)
- 오프닝 시퀀스, 사운드, 햅틱, 디바이스 연동, 남은 던전 8개, 최종 보스

### v1.0 스코프
소자 던전 12 + 최종 1 / 클래스 6+12 / 펌웨어 6 / 글리프 24 / 데몬 6 / 몬스터 40종 / 난이도 5단계

## 17. 미결 사항 (다음 논의 대상)

1. **런 길이** — 4~6던전이 8~15분에 실제로 들어맞는가? 던전당 2~3분 가정의 검증 필요.
2. **1차 전직 시점** — 2번째 던전 후가 적절한가, 아니면 런 시작 시 선택으로 할 것인가? (전자는 서사적, 후자는 빌드 계획성)
3. **Heat 도입 시점** — 튜토리얼에서 숨길 것인가, 처음부터 노출할 것인가.
4. **일일 시드 챌린지** — v1 포함 여부. 원작의 핵심 재방문 동기였음.
5. **수익 모델** — 유료 단품(₩8,900 상당) 권장. 로그라이트 퍼즐에 광고/에너지는 P1과 정면 충돌.
6. **제목 확정** — `DIE SHRINK` / `SUBSTRATE` / `TEARDOWN` / `BOARD LEVEL`
