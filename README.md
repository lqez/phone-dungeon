# phone-dungeon — DIE SHRINK

당신의 폰 화면이 투명해지고, 그 아래 기판 위에서 전자 괴물들이 기어다닌다.

Desktop Dungeons의 자원관리 퍼즐 전투를 계승하되, 무대를 스마트폰 내부 하드웨어로 옮긴
턴제 로그라이트. 폰 외관 → PCB → IC 다이 순으로 파고들며, 각 소자가 하나의 스테이지가 된다.

**▶ 플레이: https://lqez.github.io/phone-dungeon/**

## 코어 규칙

- **안개를 걷으면 회복한다.** 새로 밝힌 칸 1개당 `배터리 +레벨`, `열 −2`. 안개는 유한하다.
- **레벨업 = 배터리 완충 + 열 0.** 죽기 직전에 레벨업 타이밍을 맞추는 것이 핵심.
- **난수 없음.** 명중·회피·크리티컬 확률이 없고 모든 수치가 공개된다. 되돌리기도 없다.
- **몬스터는 움직이지 않는다.** 맵 전체가 처음부터 계산 가능한 퍼즐이다.
- **아이템은 밟는 즉시 발동한다.** 인벤토리가 없으므로 "언제 밟을지"가 전략이 된다.
- **VIA로 내려가면 배터리 최대치가 영구히 줄어든다.** 층을 갈아타며 회복만 반복할 수 없다.

자원은 `BATTERY`(체력)와 `HEAT`(마나의 역방향 게이지) 둘뿐이다.
열이 70을 넘으면 스킬 비용이 1.5배, 90을 넘으면 스킬 봉인, 100에서 3턴 셧다운.

## 개발

빌드 스텝이 없다. ES 모듈과 CDN의 three.js만 쓰므로 정적 서버로 바로 뜬다.

```bash
cd web && python3 -m http.server 8765
# → http://localhost:8765
```

`file://` 로는 ES 모듈이 로드되지 않으므로 반드시 HTTP로 열 것.

## 조작

- 인접 칸 **탭** — 이동 / 공격
- 몬스터 **길게 누르기** (데스크톱은 hover) — 교환 결과 미리보기
- 자신을 **탭** (또는 `Space`) — 스킬 휠
- 방향키 · `WASD` — 이동
- 우상단 `◱` — 카메라 기울기 전환 (12° / 26° / 40°)
